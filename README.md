# lucasnevespereira.github.io

Personal site at [lucasnp.dev](https://lucasnp.dev).

## Build

Generates `index.html` from `src/templates/<theme>/content/index.md` and minifies assets into `assets/`.

```
go run main.go
```

Theme is set in `config.yaml`.

## Preview

Serve the repo root and open the site in a browser.

```
python3 -m http.server 8000
```

- Main site: http://localhost:8000
- snowz page: http://localhost:8000/snowz

The snowz page is a standalone HTML file at `snowz.html` (not generated by the build) that reuses `/assets/css/styles.css`. Image assets live in `snowz/`.

## Deploy

Push to `main`. GitHub Pages serves from the repo root.
